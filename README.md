# 🌾 Smart Farmer

**Smart Farmer** is a responsive AgriTech frontend website designed to help farmers find cold storage, check crop market prices, and find the best buyers for their crops.

## 🚀 Features

* 🌾 Farmer Dashboard
* 🔐 Farmer Login & Registration
* ❄️ Cold Storage Search
* 📦 Storage Availability & Pricing
* 💰 Storage Cost Calculator
* 📈 Crop Market Prices
* 📊 Market Price Charts
* 🤝 Best Buyer/Vendor Suggestions
* 🏆 Buyer Comparison
* 🗺️ Interactive Map & Navigation
* 🎙️ Multilingual Voice Assistant
* 🔔 Notifications
* 👤 Farmer Profile
* 📱 Fully Responsive Design
* 💾 LocalStorage for Demo Data

## 🛠️ Technologies

* HTML5
* CSS3
* Tailwind CSS
* JavaScript
* Chart.js
* Leaflet.js
* OpenStreetMap
* Web Speech API
* LocalStorage

## 📱 Responsive

The website works on:

* Mobile 📱
* Tablet 📲
* Laptop 💻
* Desktop 🖥️

## 🎙️ Voice Assistant

The Smart Farmer voice assistant is designed to support Indian languages such as:

**Telugu, Hindi, Tamil, Kannada, Malayalam, Marathi, Bengali, Gujarati, Punjabi, Odia, Assamese and English.**

## 🎯 Project Goal

The goal of Smart Farmer is to help farmers:

**Find Storage → Check Market Prices → Find Best Buyers → Sell Better**
